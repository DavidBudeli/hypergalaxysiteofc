# Hyper Galaxy Official Site

Projeto oficial da nova experiencia publica da Hyper Galaxy, iniciado do zero no
repositorio `DavidBudeli/hypergalaxysiteofc`.

O documento mestre desta reconstrucao e a fonte de verdade:

`HYPERGALAXY_FROM_SCRATCH_MASTER_SPEC.md`

## Getting Started

Instale e rode localmente com npm:

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Foundation

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- `src` directory
- Public homepage separated from the future SaaS application
- No legacy import from the previous Hyper Galaxy site

## Current Status

Only the first execution foundation is present. Checkpoint 1 visual work must
start from `feat/checkpoint-1-experience` after approval.

## Scripts

```bash
npm run lint
npm run build
```

No deploy, merge, DNS change, authentication, database, dashboard, or backend is
part of this foundation.
